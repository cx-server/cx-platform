# List

Vertical list of items with consistent spacing, icons, info text, and optional interactive states. Supports chain/timeline visualization for step-based flows.

## When to use

| Use List when... | Don't use List when... |
|---|---|
| Displaying a series of related items vertically | You need a data grid with sorting/filtering (use a table) |
| Building navigation menus or settings panels | Items have complex multi-column layouts |
| Showing a timeline/chain of steps | You need drag-and-drop reordering |

## Anatomy

```
List (ul)
├── ListHeader (optional — title, subtitle, info, rightComponent)
└── ListItem (li)
    ├── chainIndicator (hidden unless showChain=true)
    ├── iconComponent (left icon, sized to icon-md)
    ├── ListContent
    │   ├── children (title — text-highlight, text-base, font-medium)
    │   └── subtitle (text-subtile, text-xs, font-normal)
    └── right side
        ├── info (text-standard, text-sm)
        └── rightComponent (icon/badge/chevron)
```

## Props — List

| Prop | Type | Default | Description |
|---|---|---|---|
| `id` | `string` | required | Unique identifier |
| `listSize` | `"xs" \| "sm" \| "md" \| "lg"` | `"sm"` | Gap between items |
| `hoverable` | `boolean` | `false` | Show hover background (auto-enabled on desktop) |
| `clickable` | `boolean` | `false` | Add active/ripple effect on click |
| `itemsBorder` | `boolean` | `false` | Add border to each item |
| `showChain` | `boolean` | `false` | Show chain/timeline dots and connecting lines |

## Best practices

### Do
- Use consistent sizing within a single list
- Add `clickable` + `rightComponent={<Chevron />}` for navigation lists
- Use `showChain` for step/timeline flows (verification, bet lifecycle)
- Use `info` for metadata that complements the title (amounts, dates)

### Don't
- Nest lists more than two levels deep
- Mix different sizes within the same list
- Use `showChain` for non-sequential content

## Accessibility
- Uses semantic `<ul>/<li>` for screen reader enumeration
- `htmlFor` variant uses `<label>` for form input association
- Clickable items receive ripple feedback and are keyboard-accessible
- Chain status colors are not the sole differentiator — use with text context
